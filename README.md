## ✨ Proje Hakkında

Travelio, ASP.NET Core MVC ve MongoDB kullanılarak geliştirilmiş kapsamlı bir tur ve rezervasyon yönetim uygulamasıdır.

Kullanıcıların turları inceleyebildiği, rezervasyon oluşturabildiği, favorilerini yönetebildiği, yorum ve soru paylaşabildiği; yöneticilerin ise tüm sistemi admin paneli üzerinden yönetebildiği bir yapı geliştirilmiştir.
